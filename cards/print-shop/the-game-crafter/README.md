# The Contraption Shuffle · The Game Crafter edition

One 54-card bridge-size deck with a common, reversible back and a custom printed tuckbox. The faces include 18 green Materials cards (stacked sheets), 18 blue Mechanism cards (gear), and 18 red Mission cards (flag). The rules are printed on the box and included as a separate PDF.

## Upload the game

Unzip the pack and add a Bridge Deck. All 54 faces and the reversible common back are 750 × 1125 pixels at 300 ppi.

| Component or field | File or folder | What to do |
| --- | --- | --- |
| Bridge Deck → Back | `back/common-back.png` | Upload once as the shared back. |
| Bridge Deck → Card faces | `faces/` | Select all 54 PNGs and use one copy of each. M, K, and G identify the three categories. |
| Bridge Tuck Box (54 cards) → Outside artwork | `box/bridge-tuckbox-54.png` | Add one 54-card Bridge Tuck Box. Upload the 2175 × 1800 PNG to the Outside field. |
| Player rules | `rules/Contraption-Shuffle-Common-Back-Rules.pdf` | Share or print the one-page rules separately. The box gives directions for both ways to draw. |

Use **Proof All** to review the deck, then proof the box in its component editor. Check the deck count is **54**, the back is the same on every card, and the tuckbox title and directions sit inside the fold guides. Order a single proof copy to check physical color, cut, fold and fit.

## Artwork dimensions

| Artwork | Pixels | Finished component |
| --- | --- | --- |
| All 54 faces and the common back | 750 × 1125 | 2.25 × 3.5 inch bridge card with 0.125 inch bleed on each edge |
| Tuckbox outside | 2175 × 1800 | The Game Crafter's Bridge Tuck Box (54 cards) |

The production PNGs are RGB at 300 ppi. Bleed is included, and template guides are excluded. The ZIP and PDF are for distribution. Use the individual PNGs in the print component editor.

## Play

**Three piles.** Sort by the labels on the faces. Shuffle each pile, turn it face down, and keep the order Materials, Mechanism, Mission. Draw one from each.

**One shuffled deck.** Shuffle all 54 cards. Reveal cards until you have one of each category. Keep the first of each and set aside the duplicates. Return all revealed cards and shuffle before the next round.

Use the material as a main ingredient and make the mechanism help accomplish the mission. A working model counts.
